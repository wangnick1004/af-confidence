# 準確度驗證結果

由 `benchmark/run_benchmark.py` 產生（亂數種子 20261119；AlphaFold DB 與 UniProt 資料於 2026-11-19 下載）。

抽樣蛋白質 196 個，實際使用 193 個（144 個有訊號胜肽，49 個只有起始甲硫胺酸被移除），共 735 個突變。

- 略過 1 個：UniProt 中訊號胜肽的結束位置不確定
- 略過 1 個：現行 UniProt 序列與 AlphaFold DB 模型不同（見下方）
- 略過 2 個：AlphaFold DB 沒有模型或資料讀取失敗


### 建立驗證資料時發現的真實資料不一致

- **P43251**：現行 UniProt 序列與 AlphaFold DB 模型 AF-P43251-F1 不同，位置相差 +20。它的 10 個 UniProt 突變中有 10 個照原寫法對不上模型；工具以序列更新造成的位移說明了這些突變。工具的警告原文：`the current UniProt sequence of P43251 (523 aa) differs from the AlphaFold DB model AF-P43251-F1 (543 aa): UniProt residue n = model residue n+20. Variants numbered on the current UniProt sequence will not match the model as written. AlphaFold DB model AF-P43251-4-F1 (P43251-4) has exactly the current UniProt sequence: use it for current UniProt numbering`

## 名詞說明

- **正確答案**：UniProt 天然變異的位置（依標準序列標註）。
- **第一個建議**：工具列出的第一個建議指向正確位置。
- **碰巧對上（未標示）**：改寫後的位置剛好是同一種胺基酸，工具判為對得上、沒有任何提醒。
- **標示為 ambiguous_match**：照寫法對得上，但工具發現它也符合整批的共同位移而提出警告。
